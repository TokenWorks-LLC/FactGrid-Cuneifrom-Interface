# Cuneiform fonts

`CuneiformOB.ttf` and `CuneiformNA.ttf` are the unmodified CuneiformOB and
CuneiformNA archives published by [Oracc](https://oracc.museum.upenn.edu/doc/help/visitingoracc/fonts/).
Oracc describes CuneiformOB as an Old Babylonian style and CuneiformNA as a
Neo-Assyrian style, and states that Oracc fonts are released under the
[SIL Open Font License](https://openfontlicense.org/open-font-license-official-text/).
The original font metadata retains the copyright and authorship notices.
CuneiformOB embeds the full OFL 1.0 text; CuneiformNA names the OFL without a
version. The current [OFL 1.1 text](./OFL-1.1.txt) is included here for
reference. Neither archive supplied a separate license file.
